러닝 기록, 자동으로 모으기 ⌚
각자 쓰는 앱은 달라도 괜찮아요. 목표는 하나 — 두 사람의 기록을 Strava(무료 러닝 앱)로 모으는 거예요. 한 번만 설정하면 그 뒤로는 전부 자동이에요.
⌚ 가민👟 나이키런📱 갤럭시🍎 아이폰→🟠 Strava→💕 이 앱
다 되면: 뛰고 나서 아무것도 안 해도 달력에 러닝 기록이 자동으로 생기고(거리·시간·페이스), 지도에 뛴 경로가 그려지고, 어느 러닝 스팟에서 뛰었는지도 붙어요.
0단계 · 둘 다 하기 — Strava 가입 5분 · 무료
  1. 앱스토어/플레이스토어에서 Strava(스트라바) 설치
  2. 회원가입 (구글/애플 계정으로 가입하면 빨라요)
  3. 끝! 아래에서 자기 앱에 맞는 카드 하나만 따라 하면 돼요
⌚ 가민 시계로 뛰면 제일 쉬움 · 공식 지원
  1. 폰에서 Garmin Connect 앱 열기
  2. 더보기(≡) → 설정 → 연결된 앱(커넥티드 앱)
  3. Strava 선택 → Strava 로그인 → 승인
  4. 끝! 이제 시계로 뛰면 경로·페이스·심박까지 알아서 넘어가요
📱 갤럭시 (삼성헬스)로 뛰면 쉬움 · 앱 하나 필요
  1. 플레이스토어에서 Health Sync 설치 (삼성헬스↔다른 앱을 이어주는 앱)
  2. 처음 열면 물어봐요 — 동기화 원본: 삼성헬스 / 대상: Strava 선택
  3. 삼성헬스 접근 권한 허용 + Strava 로그인·승인
  4. 동기화 항목에서 활동(운동) 켜기 → 끝!
⚠️ 무료 체험 후 몇천 원 한 번 결제하는 앱이에요. 광고 없고 한 번 사면 계속 쓰는 방식 — 이 용도로는 사실상 표준이에요.
🍎 아이폰 (건강·피트니스·애플워치)으로 뛰면 쉬움 · 앱 하나 필요
  1. 앱스토어에서 HealthFit 설치 (커피 한 잔 값, 한 번만 결제)
  2. 건강 데이터 접근 모두 허용
  3. HealthFit 설정에서 Strava 연결 → 로그인·승인
  4. 자동 내보내기(Auto Export) 켜기 → 끝! 뛰면 알아서 넘어가요
무료로 하고 싶으면 RunGap 앱도 돼요 — 보는 건 무료, 내보내기만 시즌권 결제예요.
👟 나이키 런 클럽(NRC)으로 뛰면 우회 필요
나이키가 몇 년 전 외부 연동을 막아서 공식 방법이 없어요. 대신 이렇게 하면 경로까지 통째로 넘어가요:
  1. 아이폰: RunGap 설치 → 계정 연결에서 Nike 로그인 → Strava 연결 → 자동 동기화 켜기
  2. 갤럭시: SyncMyTracks 설치 → 원본 Nike / 대상 Strava 연결
💡 솔직한 추천: 나이키런을 꼭 써야 하는 게 아니면, 러닝 앱을 Strava로 갈아타는 게 제일 속 편해요. 기록·경로·페이스 다 되고 우회 앱도 필요 없어요.
💕 마지막 · 이 앱과 잇기 🔌 준비 중
여기까지 하면 두 사람 기록이 Strava에 모여요. 이 앱이 자동으로 가져오게 하는 마지막 연결은 딱 한 번, 창석이 하면 돼요:
  1. strava.com 로그인 → strava.com/settings/api 접속
  2. 앱 만들기 — 이름은 아무거나(예: 계획하는사이), 웹사이트에 이 앱 주소 입력
  3. 발급된 Client ID와 Client Secret을 클로드에게 전달
  4. 그러면 이 화면에 [Strava 연결하기] 버튼이 생기고, 달력 자동 기록 + 지도 경로 그리기가 켜져요 ✨

나라가 주는 혜택 🎁
청년 · 예비/신혼부부가 챙길 만한 것들. 조건과 금리는 자주 바뀌니 신청 전에 꼭 최신 공고를 확인해요!
🏡 주택청약종합저축 (일명 분양 적금) 누구나 가입 가능, 월 2만~50만원 자유 납입. 아파트 분양(민영·국민주택) 청약 자격의 기본이고, 연말정산 소득공제 혜택도 있어요. 결혼 전 각자 하나씩 유지하는 게 기본기!
💜 청년 주택드림 청약통장 만 19~34세 + 소득 조건 충족 시 일반 청약통장보다 우대금리·비과세 혜택. 이미 청약통장이 있으면 전환 가능한지 은행에 물어보세요.
💰 청년도약계좌 만 19~34세 대상, 5년 납입하면 정부기여금을 얹어주는 목돈 만들기 계좌. 소득 구간별로 지원이 달라요.
💒 신혼부부 특별공급 (특공) 혼인 7년 이내(예비부부 포함되는 공고도 있음) 대상의 아파트 분양 특별공급. 결혼 준비 중이라면 무조건 알아둘 제도!
🏠 신혼부부 버팀목 전세대출 · 디딤돌 구입대출 주택도시기금의 저금리 대출. 전세는 버팀목, 매매는 디딤돌. 신혼(혼인 7년 이내) 우대 조건이 따로 있어요.
👶 신생아 특례대출 출산 가구 대상의 초저금리 주택 대출. 아이 계획이 있다면 시기 맞춰 챙기면 이자 차이가 커요.

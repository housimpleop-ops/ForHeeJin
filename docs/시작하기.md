# 시작하기 — 딱 3단계

비개발자 기준으로 적었어요. 순서대로 하면 됩니다. (전부 무료)

## 1단계. Supabase 준비 (약 5분)

1. https://supabase.com 로그인 (기존 계정 그대로)
2. **New project** 클릭 → 이름 `couple-planner` → 리전 `Northeast Asia (Seoul)` → 비밀번호는 아무거나 만들고 메모 → **Create**
   - ⚠️ HOUSIMPLE-ERP 프로젝트를 같이 쓰지 말고 새로 만드는 걸 추천 (회사 데이터와 분리)
3. 왼쪽 메뉴 **SQL Editor** → **New query** → 이 저장소의 `supabase/couple-schema.sql` 내용 전체를 붙여넣고 **Run**
4. 왼쪽 메뉴 **Authentication → Users → Add user → Create new user**
   - 이메일·비밀번호 입력 (창석용). "Auto Confirm User" 체크!
   - 희진이 것은 나중에 같은 방법으로 하나 더.
5. **Project Settings → API** 에서 두 값을 복사:
   - Project URL
   - anon public 키
6. 복사한 두 값을 클로드에게 알려주거나, 직접 `js/config.js`에 붙여넣기

## 2단계. GitHub Pages에 올리기 (약 5분)

1. https://github.com 로그인 (housimpleop-ops 계정)
2. 오른쪽 위 **+** → **New repository** → 이름 `couple-planner` → **Public** 선택 → **Create repository**
3. 클로드에게 "저장소 만들었어"라고 말하면 코드를 올려줌
4. 올라간 뒤: 저장소 페이지 → **Settings → Pages** → Branch를 `main` / `/ (root)` 선택 → **Save**
5. 1~2분 뒤 `https://housimpleop-ops.github.io/couple-planner/` 에서 접속 가능

## 3단계. 폰에 설치

- 갤럭시(크롬): 주소 열기 → ⋮ 메뉴 → **홈 화면에 추가**
- 아이폰(사파리): 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- 열리면 로그인 화면에서 1단계 4번에서 만든 이메일·비밀번호 입력 (한 번만, 이후 유지됨)

## 자주 묻는 것

- **데이터는 어디에?** Supabase의 couple_state 테이블 + couple-media 저장소. 로그인한 사람만 읽고 쓸 수 있어요.
- **주소를 남이 알면?** 앱 화면은 열리지만 로그인 없이는 데이터가 안 보여요.
- **사진/영상은?** 링크를 정확히 아는 사람만 볼 수 있는 공개 저장소 방식이에요. 더 단단히 잠그는 건 다음 버전에서 가능.
- **설정 전에도 써져요?** 네, config.js가 비어 있으면 "이 기기에만 저장" 모드로 동작해요.
